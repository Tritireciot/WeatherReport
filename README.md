# Weather-Report — отображение текущей погоды (Yandex Weather API)

Десктопное Qt5-приложение для отображения текущей погоды (температура, давление, ветер, влажность) с поддержкой светлой/тёмной темы и асинхронных REST-запросов без блокировки GUI.

## Авторизация

В рамках этого приложения **уникальным пользователем считается API-ключ** Yandex Weather API.

- В меню **Настройка → Авторизация** пользователь вводит:
  - **Логин** — отображаемое имя (показывается в интерфейсе)
  - **Пароль** — API-ключ Yandex Weather API (используется для запросов)
- Успешность авторизации отображается индикатором (лампочка):
  - зелёный — авторизация успешна
  - красный — авторизация неуспешна
- Кнопка **«Обновить»** недоступна (disabled), если авторизация не пройдена.

## Требования

- CMake >= 3.16
- Компилятор с поддержкой C++17
- Qt 5 (модули: Widgets, Network)

## Сборка и запуск

### Linux / macOS

```bash
cmake -S . -B build
cmake --build build -j
./build/WeatherReport
```
